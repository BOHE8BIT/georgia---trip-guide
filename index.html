🚞 夜间小火车与缆车攻略

Narikala Cable Car｜夜间小火车

  1. 从 Rike 广场乘坐，18:00–21:00 适合日落与夜景。
  2. 现场自助购票，现金或信用卡以机器支持为准。
  3. 路线：Rike 广场 → 古堡观景台 → 原路下山。
  4. 山顶风大，穿外套；古堡周边留意禁飞标识。

Tbilisi Funicular｜第比利斯小缆车

  1. 老式轨道缆车，与 Narikala 城市观景缆车不同。
  2. 车厢内适合拍靠窗侧光、牵手和互动特写。
  3. 上山平台适合复古电影感情侣合照。
  4. 天气变化时按现场运营公告调整。

🎁 伴手礼推荐

  • 第比利斯老城市集｜Tbilisi Old Town Market：陶瓷杯、饰品、香料。
  • Goodwill 超市｜Goodwill Tbilisi Old Town：红酒、蜂蜜、Adjika。
  • 卡兹别克小镇｜Stepantsminda：高山野花蜂蜜。

🌤️ 气候、护肤与穿搭

第比利斯 18–24℃；卡兹别克 5–14℃，风大干燥。

准备保湿面霜、防晒、唇膏、护手霜、薄外套、防风厚外套和防滑徒步鞋。

📸 拍照滤镜与无人机规则

  • 城市街巷：Dazz Classic U3 / 复古 NC；极影 EK1。
  • 咖啡馆：Dazz D Filt；极影 FN1。
  • 和平桥：蓝调时刻牵手、行走、剪影。
  • Gergeti：教堂下三分之一，天空与雪山留足空间。
  • 木屋露台：逆光轮廓、并肩看雪山。

⚠️ 无人机提醒

城市和古堡部分区域禁飞；山区起飞前确认现场规定。Mini 4 Pro 遇大风不要起飞，电池随身携带、不可托运。
