🚞 专项攻略｜夜间小火车与缆车

点击标题收起

夜间小火车 / Narikala Cable Car

  1. 导航：Narikala Cable Car Rike Station（Rike 广场河边）。
  2. 推荐 18:00–21:00，10 月约 19:00 城市灯光完全亮起。
  3. 现场自助机购票，票价以当天公告为准；现金/信用卡按现场支持方式购买。
  4. 路线：Rike 广场上山 → 古堡观景台拍照 → 原路下山。
  5. 山顶风大，穿外套；古堡区域留意禁飞标识，夜景优先地面拍摄。

第比利斯小缆车 / Tbilisi Funicular

  1. 它是老式轨道缆车，与 Narikala 城市观景缆车不同。
  2. 车厢内适合拍靠窗侧光、牵手和互动特写。
  3. 上山平台俯瞰城市，适合复古电影感情侣合照。
  4. 大风或天气变化时，按现场运营公告调整安排。
